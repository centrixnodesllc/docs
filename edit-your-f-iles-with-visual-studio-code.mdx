### Installing the Visual Studio Code Plugin

1. Install the Pterodactyl SFTP Plugin in the extension marketplace you can install from this link [Pterodactyl SFTP | Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=minhmcpc.pterodactyl-sftp) It will redirect you to your vscode install.

![Image](/images/image.png "Image")

#### Creating your API Credentials

1. Navigate to your panels accounts page or click this link [CentrixNodes Panel | Accounts](https://panel.centrixnodes.net/account) 
2. Navigate to the **API Credentials** or **API Keys** Tab
   <img
     src="/images/image-3.png"
     alt="Image"
     title="Image"
     style={{ width:"49%" }}
   />
3. Next your going to click **Add a Key** or **New Key.**
   ![Image](/images/image-4.png "Image")

4. Next your going to create a description for you key you can name it whatever you wany but for this example I will name it VSCODE. For security reasons I would recommend you whitelisting your ip but it is not needed. Next copy the key that was provided.
   ![Image](/images/image-8.png "Image")

### Finishing configuration

1. Go back to your vscode and paste the key that was provided.

<Note>
  Make sure to have **Auto-configure SSH Key Selected.**
</Note>

![Image](/images/image-9.png "Image")

2. Click add account
